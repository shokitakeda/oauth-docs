プライバシーポリシー

最終更新日：2026-09-16

本ツール「AI朗読チャンネル分析ツール」（以下「本ツール」）は、開発者本人（竹田匠希）が、自身が運営するYouTubeチャンネルの分析・レポート作成のために個人で開発・利用している内部ツールです。本ページは、本ツールが取得するデータの取り扱いについて説明するものです。

取得するデータ

本ツールは、YouTube Data API および YouTube Analytics API を通じて、開発者本人が所有・管理するYouTubeチャンネルについて、次のデータを取得します。

  • 動画のメタデータ（タイトル・公開日・再生時間 等）
  • 再生数・高評価数などの公開指標
  • 視聴維持率・平均視聴時間・トラフィックソース別の再生数など、チャンネル所有者のみが閲覧できる非公開の分析指標

本ツールが利用するアクセス権の範囲（スコープ）は次のとおりです。

  • yt-analytics.readonly（視聴維持率・トラフィックソースの読み取り）
  • youtube.readonly（チャンネル情報の読み取り）
  • youtube.force-ssl（コメント等の読み取り）

利用目的

取得したデータは、開発者自身のチャンネル運営における意思決定（投稿内容・投稿スケジュール・企画の改善等）のための内部レポート作成にのみ使用します。広告配信・第三者へのマーケティング・データの販売等には一切使用しません。

データの保存・共有

取得したデータは、開発者個人が管理するローカル環境および開発者が契約する業務管理サービス（Addness）にのみ保存されます。第三者への提供・販売・公開は行いません。

データの保持期間・削除

取得したデータは、社内レポート作成の目的で保持し、不要になった時点で開発者の判断により削除します。ユーザー（開発者本人）は、いつでも下記の方法でアクセス権を取り消すことができます。

  • Googleアカウントの「アカウント管理」→「セキュリティ」→「サードパーティのアプリとサービス」から、本ツールへのアクセス権を取り消す
