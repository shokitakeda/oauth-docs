AI朗読チャンネル分析ツールについて

このページは、YouTube API の利用に関する説明のために公開しています。一般向けの製品・サービスではありません。

これは何か

竹田匠希が個人で運営する複数のYouTubeチャンネル（人生は七転び八起き／龍玄組／スカッとうららか 等）について、自分自身のチャンネル運営の意思決定に使うための、内部向けの分析・レポート作成ツールです。

何をするか

YouTube Data API および YouTube Analytics API を通じて、開発者本人が管理するYouTubeチャンネルの再生数・視聴維持率・トラフィックソースなどのデータを取得し、日々の運営判断のためのレポートを自動的に作成します。

誰が使うか

開発者本人（竹田匠希）のみが、自分のチャンネルのデータを見るために使用します。一般公開はしておらず、第三者への提供や再配布は行っていません。
